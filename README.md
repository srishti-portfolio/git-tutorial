# Git Tutorial Practice Repository

This repository was created to practice Git and GitHub while learning from a tutorial.

## Purpose

The main purpose of this repository is to understand how Git and GitHub work in real projects, including:

- Creating repositories
- Adding and committing files
- Understanding version control
- Pushing code to GitHub
- Working with folders and project structure

## Learning Source

This repository was created while following a Git & GitHub tutorial for learning purposes.

## Notes

This is a practice repository and is not meant to be a final project.
It is used only for learning and experimenting with Git commands and GitHub features.
